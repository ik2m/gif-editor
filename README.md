# GIF Editor

ローカルの動画から、複数の範囲を切り出して GIF を作成するブラウザアプリです。
動画はすべてブラウザ内で処理され、どこにもアップロードされません。

## 使い方

```bash
npm install
npm run dev      # 開発サーバー（http://localhost:5173）
npm run build    # dist/ に静的ファイルを出力
npm test         # ユニットテスト
```

1. 「動画を開く」またはドラッグ＆ドロップで動画を読み込む
2. 範囲を作る（複数可・重なり可）
   - タイムライン下段の空き部分をドラッグ
   - `I` / `O` で開始点・終了点を決めて `Enter`
   - 右の一覧で開始・終了を数値で直接入力
3. 範囲ごとに「GIF出力」、またはまとめて「すべてZIPで出力」

## 仕様

| 項目 | 内容 |
| --- | --- |
| 範囲の単位 | 秒／フレームを切替。範囲は `[開始, 終了)` で保持し、フレーム表示では終了フレームを含む形で表示 |
| 元動画のFPS | ブラウザから取得できないため、`requestVideoFrameCallback` で再生して自動推定。手動で修正可能 |
| 範囲の編集 | タイムラインでドラッグ移動・両端で伸縮、「現在位置」ボタン、数値入力。重なる範囲は別の段に表示 |
| プレビュー | 範囲ごとにループ再生。生成後は GIF のサムネイルとファイルサイズを表示 |
| 出力設定 | FPS（1〜50）・横幅・色数（8〜256）・ループ有無。共通設定に加え、範囲ごとに個別設定で上書き可能 |
| 出力 | 範囲ごとに個別ダウンロード、または全範囲を ZIP で一括ダウンロード。範囲や設定を変えると再生成 |

### ショートカット

| キー | 動作 |
| --- | --- |
| `Space` | 再生／一時停止 |
| `←` `→` | 1フレーム移動（`Shift` で1秒） |
| `I` / `O` | 開始点／終了点を現在のフレームに設定 |
| `Enter` | 開始点〜終了点を範囲として追加 |
| `Esc` | 開始点・終了点をクリア |
| `L` | 選択中の範囲をループ再生 |
| `Delete` | 選択中の範囲を削除 |

## 構成

- `src/main.ts` — 状態管理・UI
- `src/timeline.ts` — タイムライン（目盛り・範囲の段組み・ドラッグ操作）
- `src/encoder.ts` — 動画フレームの取得と GIF エンコード（[gifenc](https://github.com/mattdesl/gifenc)）
- `src/fps.ts` — 元動画の FPS 推定
- `src/time.ts` — 時間／フレーム変換などの純粋関数（`time.test.ts` でテスト）

ZIP 作成には [fflate](https://github.com/101arrowz/fflate) を使用しています。
再生できる動画形式はブラウザに依存します（例：H.265/HEVC はブラウザによっては非対応）。
